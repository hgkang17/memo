# 메모 스티커

Windows 바탕화면에서 사용하는 PySide6 기반 메모 위젯입니다. 창은 하나만 열리고, 그 안에 여러 개의 메모 카드를 추가할 수 있습니다. 모든 변경 사항은 로컬 SQLite 데이터베이스에 자동 저장됩니다.

## 현재 기능

- 하나의 위젯 창 안에 여러 메모 카드 추가
- 카드별 제목과 리치 텍스트 본문 자동 저장
- 카드별 작성 일시와 최종 수정 일시 표시
- 실제 내용·완료·서식이 바뀔 때만 수정 일시 갱신
- 카드 아래 손잡이로 메모별 높이 조절 및 자동 저장
- 제목 줄의 아이콘으로 형광펜과 글자색 변경
- 최근 선택 색상을 기억해 아이콘 본체를 누르면 즉시 재적용
- 본문 줄별 체크박스와 체크된 줄의 회색·취소선 표시
- 카드별 투명도 100%·85%·70%·55% 설정
- 진행 중인 메모는 흰색 배경으로 표시
- `완료` 체크 시 해당 카드만 회색으로 전환
- 완료 상태 해제 및 재편집
- 스크롤 가능한 메모 목록
- 공용 창 위치와 크기 기억
- 메모 제목 목록에서 원하는 카드로 바로 이동
- 창을 항상 위에 표시하는 선택 옵션
- 시스템 트레이에서 숨긴 창 다시 열기
- `Win+D` 후 복원해도 바탕화면 클릭만으로 다시 사라지지 않는 정상 Windows 창 동작
- 최소화와 트레이 숨기기를 별도 동작으로 제공
- 숨기기와 영구 삭제의 명확한 구분
- 완전히 투명한 상단 레일과 카드 사이 영역
- GitHub Release 자동 업데이트 확인 및 단일 EXE 자동 교체

## CMD 창 없이 실행

탐색기에서 [run.bat](run.bat)을 더블클릭하면 `pythonw.exe`로 실행되므로 CMD 창이 남지 않습니다. [MemoSticker.pyw](MemoSticker.pyw)를 직접 실행해도 됩니다.

처음 설치할 때만 PowerShell에서 다음을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

개발 중 콘솔 오류를 확인하려면 다음 명령을 사용할 수 있습니다.

```powershell
python main.py
```

## 사용법

- 상단 `메모 추가` 또는 `Ctrl+N`으로 같은 창 안에 메모 카드를 추가합니다.
- 창 상단의 빈 공간을 드래그하면 위젯 전체가 이동합니다.
- 우측 하단을 드래그하면 위젯 크기가 바뀝니다.
- 카드 본문에서 글자를 선택하고 형광펜·글자색 아이콘의 화살표에서 색을 고릅니다. 다음부터는 아이콘 본체를 누르면 선택했던 색이 바로 적용됩니다.
- 본문 줄에 커서를 둔 뒤 체크박스 아이콘을 누르면 그 줄이 할 일 항목이 됩니다. 본문 왼쪽 체크박스를 누르면 해당 줄만 회색 취소선으로 전환됩니다.
- 카드 맨 아래의 짧은 손잡이를 위아래로 드래그하면 해당 메모만 높이가 바뀝니다. 더블클릭하면 기본 높이로 돌아갑니다.
- 키보드로 손잡이에 포커스한 뒤 `↑`/`↓`를 눌러도 높이를 조절할 수 있습니다. `Shift`와 함께 누르면 더 크게 조절됩니다.
- 카드의 `완료`를 체크하면 해당 카드만 회색 읽기 전용 상태가 됩니다. 체크를 해제하면 다시 편집할 수 있습니다.
- 카드의 `설정 → 투명도`에서 카드별 투명도를 바꾸거나, `메모 삭제`로 영구 삭제할 수 있습니다.
- 상단 `메뉴 → 메모 제목으로 모아보기`에서 원하는 제목을 눌러 해당 카드로 이동합니다.
- `—` 버튼은 작업표시줄 최소화, `X` 버튼은 시스템 트레이로 숨기기입니다.
- 우측 상단 닫기 버튼은 앱 종료가 아니라 창 숨기기입니다. 시스템 트레이 아이콘에서 다시 열 수 있습니다.
- `메뉴 → 바탕화면에서 항상 표시`를 켜면 다른 프로그램 위에도 계속 보입니다. 기본값은 꺼짐입니다.
- 앱을 완전히 끝내려면 상단 `메뉴 → 앱 종료` 또는 트레이 메뉴의 `종료`를 사용합니다.

## 데이터 위치

데이터는 Qt가 제공하는 Windows 사용자 앱 데이터 경로 아래 `LocalTools/MemoSticker/memos.db`에 저장됩니다. 이전 버전에서 만든 메모도 같은 데이터베이스에서 읽어 단일 창의 카드로 표시합니다.

## 단일 EXE와 업데이트

[GitHub Releases](https://github.com/hgkang17/memo/releases)에서 `MemoSticker.exe` 하나만 내려받아 실행하면 됩니다. 설치 과정이나 별도 Python 환경은 필요하지 않습니다.

- 시작 후 최대 6시간에 한 번 새 릴리즈를 자동 확인합니다.
- `메뉴 → 업데이트 확인`으로 즉시 확인할 수도 있습니다.
- 새 버전을 승인하면 EXE를 내려받고 SHA-256을 검증한 뒤 현재 파일을 교체하여 다시 실행합니다.
- 휴대용 EXE와 데이터베이스는 분리되어 있으므로 업데이트해도 메모는 유지됩니다.

로컬에서 릴리즈 파일을 만들려면 다음을 실행합니다.

```powershell
pip install -r requirements-build.txt
.\build_release.ps1
```

태그 `v1.0.0`처럼 `memo_widget/version.py`의 버전과 같은 태그를 푸시하면 GitHub Actions가 Windows 단일 EXE와 체크섬을 릴리즈에 자동 등록합니다.

## 구현 범위

현재 구현은 프레임리스 최상위 창의 바탕, 카드 사이 공간, 스크롤 영역을 투명하게 만들어 바탕화면에 놓인 것처럼 보이게 합니다. 다만 이것은 시각적 임베딩이며, 창 자체는 일반 Windows 최상위 창입니다. Windows Explorer의 `WorkerW` 레이어에 직접 붙이는 진짜 바탕화면 임베딩은 Explorer 재시작과 Windows 업데이트에 취약하므로 적용하지 않았습니다.
